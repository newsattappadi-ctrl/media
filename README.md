# News Attappadi media

Post images for the News Attappadi (@newsattappadi) Facebook and Instagram page.

- `posts/YYYY-MM-DD/slide1.png ...` : carousel slides for each day (1080x1350).
- `tools/build.py` : builds the slides in the page's brand style from a `content.json` file. Usage is in the file header.
- `tools/brand/logo.jpg` : page logo.

Public image link format:
`https://raw.githubusercontent.com/newsattappadi-ctrl/media/main/posts/YYYY-MM-DD/slideN.png`
